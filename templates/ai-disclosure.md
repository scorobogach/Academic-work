# Раскрытие использования ИИ

> Выберите вариант под требования конкретного журнала/вуза и **проверьте его
> редакционную политику**: формулировки и требуемый объём раскрытия отличаются.
> При отсутствии требований disclosure всё равно лучше сделать.

## Машиночитаемый лог (источник для этого раздела)

```json
{
  "type": "note",
  "actor": "human",
  "payload": {
    "kind": "ai_use",
    "section": "Методы",
    "authorship": "human_draft_model_edit",
    "model": "<модель и версия>",
    "tasks": ["стилистическая правка", "проверка согласованности терминов"],
    "human_verification": ["числа сверены с results.json", "цитаты сверены с PDF"],
    "disclosure_required": true,
    "date": "2026-09-21"
  }
}
```

Значения `authorship`:
`human_only` · `human_draft_model_edit` · `model_draft_human_edit` ·
`model_draft_human_rewrite` · `model_generated_unchecked` (недопустимо для сдачи).

## Таблица по разделам

| Раздел | Роль ИИ | Проверка человеком | Раскрывать |
|---|---|---|---|
| Введение | поиск литературы, не текст | да | да |
| Методы | правка стиля | да | да |
| Результаты | форматирование таблиц из `results.json` | да | да |
| Обсуждение | обсуждение аргументов, не генерация текста | да | да |
| Выводы | не использовался | — | нет |

## Чего не должно быть в disclosure

- общих фраз без конкретики («использовались современные технологии»);
- утверждений о проверке, которой не было;
- указания модели без указания того, что именно она делала;
- умолчания о генерации изображений или данных, если они были.
