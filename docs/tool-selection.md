## Правила выбора инструментов (вывод)

1. **Лицензия важнее звёзд.** 48k★ под CC BY-NC нельзя включить в MIT-репозиторий.
   0★ с понятной архитектурой полезнее 20k★ с чужой лицензией.
2. **Проверять дату последнего push.** Из пяти «проектов для проверки утверждений»
   три не обновлялись месяцами.
3. **Облачный сервис = передача неопубликованного текста третьей стороне.**
   Для черновика это отдельное решение, а не настройка по умолчанию.
4. **Инструмент, удаляющий маркеры происхождения, в научном пайплайне не место.**
   Сохраняйте provenance, добавляйте disclosure.
5. **Детерминированные проверки — сначала.** Они бесплатны, быстры и
   воспроизводимы; модельные — потом и с записью результата.
