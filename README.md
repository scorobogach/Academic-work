## Зачем это

Три требования, которые обычно ставят перед такой системой, и честный ответ на каждое:

| Требование | Что реально достижимо | Что делает этот репозиторий |
|---|---|---|
| «Убрать следы и маркеры ИИ из текста» | Убрать **технический брак** (невидимые символы, bidi-контролы) и **шаблонную «воду»** — да, это вопрос качества. «Обмануть детектор» — нет: это не повышает достоверность и конфликтует с правилами раскрытия использования ИИ | Гейты **G0** и **G1** + русские словари в `config/style-rules.ru.json` |
| «Всё должно быть проверено и реально» | Ссылки и утверждения — проверяемы. **Реальность эксперимента** доказывается не текстом, а сырыми данными, кодом, окружением и воспроизведением | Реестры `evidence` / `claims` / `decisions`, гейты **G3–G6**, манифест данных |
| «В памяти должен сохраняться весь диалог, чтобы не возвращаться» | Да: **неизменяемый полный журнал** + отдельная поисковая память. Саммари не заменяет журнал | `journal/YYYY-MM.jsonl` с хеш-цепочкой, SQLite+FTS5, MCP-сервер, `make resume` |

**Ключевое различие, которое всё определяет:** полный журнал (append-only, доказуемо
неизменяемый) — это истина; саммари, «факты» и векторная память — производные
индексы, которые можно пересобрать и потерять. Нельзя заменить первое вторым.

## Быстрый старт

```bash
git clone https://github.com/scorobogach/Academic-work.git
cd Academic-work

# 1. убедиться, что всё работает (Python 3.9+, без установки зависимостей)
make test                      # 94 теста

# 2. создать личное хранилище (БД + журнал лежат вне репозитория)
make init                      # ~/.academic/journal.db и ~/.academic/journal/

# 3. подключить MCP-сервер к агенту
python3 scripts/install_mcp.py --agent all      # claude | cursor | codex | all
#    перезапустите агента и попросите: «вызови journal.verify»

# 4. прогнать детерминированные гейты по рукописи
make gates MANUSCRIPT=examples/minimal/main.tex BIB=examples/minimal/refs.bib \
            VALUES=examples/minimal/analysis/results.json

# 5. начать сессию с контекст-пака вместо пересказа истории
make resume
```

Ноль внешних зависимостей: журнал, БД, гейты и MCP-сервер работают на стандартной
библиотеке Python. Ни pip install, ни Docker, ни сети (кроме опциональной проверки
DOI через Crossref).

### Три хранилища — три разные политики

| Слой | Что хранит | Где живёт | Свойства |
|---|---|---|---|
| **Журнал** (истина) | все сообщения, вызовы инструментов, файлы, прогоны гейтов | `~/.academic/journal/YYYY-MM.jsonl` | append-only, хеш-цепочка, проверяется `make journal-verify` |
| **Реестры** (структура) | evidence, claims, decisions, gates | `~/.academic/journal.db` (SQLite + FTS5), экспорт в CSV/Markdown | редактируемые, индексируемые |
| **Память** (поиск) | решения, ограничения, уроки — производные индексы | Engram / agentmemory | перезаписываемая, со ссылкой на `journal_id` |

## Quality-gates

Порядок обязателен: сначала бесплатные детерминированные проверки, потом модельные.

| # | Гейт | Что проверяет | Кто выполняет | Блокирующий |
|---|---|---|---|---|
| **G0** | `hygiene` | невидимые Unicode, bidi-контролы, смешанная типографика | скрипт | ✅ |
| **G1** | `style` | шаблонные обороты, «вода», unsourced claims, ритм, тире (порог 90/100) | скрипт | ✅ (`UNSOURCED` — всегда) |
| **G2** | `fidelity` | не изменились ли числа, цитаты, оговорки и выводы после правки | второй агент | ✅ |
| **G3** | `bibliography` | каждая ссылка существует, есть DOI/URL, метаданные полные; опционально — сверка с Crossref | скрипт (± сеть) | ✅ |
| **G4** | `claim_alignment` | у каждого утверждения есть источник, локатор (страница/абзац) и verbatim-совпадение цитаты | скрипт + человек | ✅ |
| **G5** | `numbers` | каждое число в тексте **и в таблицах** трассируется на `results.json` | скрипт | ⚠️ настраивается |
| **G6** | `reproducibility` | таблицы и фигуры пересобираются из сырых данных одной командой | `make reproduce` | ✅ |
| **G7** | `disclosure` | лог использования ИИ, раздел disclosure, конфликт интересов, человеческая подпись | `make disclosure` + человек | ✅ |
| **G8** | `figures` | рисунки: файл существует, есть подпись и метка, числа трассируются, рисунок не старше данных | скрипт | ✅ |
| **GX** | `canary` | recall контура: подмешанные ложные утверждения и ссылки должны быть найдены | скрипт | ✅ при recall < 0.8 |

Отдельно, **раз в месяц и перед сдачей**: `make canary-run` — в копию черновика
подмешиваются 5 ложных утверждений, 3 несуществующие ссылки и число, которого нет
в `results.json`; считается recall контура. Recall < 0.8 — «зелёный» статус гейтов
перестаёт учитываться. Гейт без измерения собственных ошибок — это вера, а не контроль.

```bash
make canary-run MANUSCRIPT=manuscript/main.tex BIB=manuscript/refs.bib \
                 VALUES=analysis/results.json      # recall 1.00 на примере из examples/
```

Подробности: [docs/gate-reference.md](docs/gate-reference.md).

## MCP-инструменты

| Инструмент | Назначение |
|---|---|
| `journal.append` | записать событие в неизменяемый журнал |
| `journal.search` | полнотекстовый поиск (FTS5) по всему, что когда-либо обсуждалось |
| `journal.verify` | проверить хеш-цепочку журнала |
| `claims.upsert` / `claims.list` / `claims.summary` | реестр проверяемых утверждений |
| `evidence.upsert` / `evidence.list` | реестр источников |
| `decisions.upsert` / `decisions.list` | реестр решений («не возвращаться к решённому») |
| `gates.record` / `gates.latest` | фиксация прогонов, включая модельные гейты |
| `resume.build` | контекст-пак для старта сессии |
| `text.check` | быстрые проверки G0+G1 прямо в диалоге |

Тот же набор доступен из CLI: `python3 scripts/journal_cli.py --help`.
Дополнительные команды: `gate-quote` (разовая сверка цитаты), `run-gate G4/G8`,
`export` (CSV/Markdown), `canary` / `canary-check` (GX), `disclosure`,
`bib-import` / `bib-export` (синхронизация .bib с реестром источников).

## Ограничения (читать обязательно)

1. **Никакой пайплайн не доказывает, что эксперимент был проведён.** Проверяется
   текст, ссылки, согласованность артефактов и воспроизводимость пересчёта.
   Реальность исследования подтверждается сырыми данными, протоколом, журналами
   и независимым воспроизведением — это ответственность человека.
2. **Гейт стиля — не детектор ИИ и не средство его обхода.** Он убирает
   технический брак и пустые обороты. Цель — точность и ясность, а не маскировка.
3. **Журнал — не публичный артефакт.** Он содержит персональные данные и
   неопубликованные результаты. Держите его вне git
   ([docs/privacy-and-legal.md](docs/privacy-and-legal.md)).
4. **G2, G4, G6, G7 детерминированно не проверяются.** Это модельные и человеческие
   гейты; скрипт только фиксирует их результат и делает его проверяемым позже.

## Почему только стандартная библиотека

Журнал должен открываться через годы, на чужом компьютере и без интернета.
Каждая внешняя зависимость — это риск, что проверка целостности окажется
невозможной именно тогда, когда она понадобится. Поэтому: `json`, `sqlite3`,
`hashlib`, `urllib` — и ничего больше. Опциональные интеграции (Engram, CiteCheck,
ARS) подключаются снаружи и не являются обязательными.
