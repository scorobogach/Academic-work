# Правила работы агента в этом проекте

Короткий набор инструкций для Claude Code / Codex / Cursor. Читается агентом
автоматически. Подробности — в [docs/session-protocol.md](docs/session-protocol.md).

## Главное правило

**Нет источника — нет утверждения.** Если для утверждения нет источника,
локатора (страница/абзац) и verbatim-цитаты, оно получает вердикт
`unverifiable` и **не попадает в рукопись**. Не «дописывай по памяти»:
ни числа, ни фамилии, ни года, ни названия.

## Начало сессии

1. Вызови MCP-инструмент `resume.build` (или `make resume`) и прочитай контекст-пак.
2. Не переспрашивай о решениях со статусом `active` — они в пакете.
3. Если есть `blocking`-утверждения, начни с них.

## Во время сессии

- Каждое фактическое утверждение → `claims.upsert` со статусом `open`.
- Каждый источник → `evidence.upsert` (DOI/PMID/URL, `trust_tier`, путь к PDF).
- Каждое решение → `decisions.upsert` с полями `rationale` и **`reopen_if`**.
- Каждое изменение рукописи → `journal.append` (тип `file`, хеш версии).
- Каждый прогон гейта → `gates.record` с вердиктом и стоимостью.

## Редактура текста

- Разрешено: убирать невидимые символы, пустые и шаблонные обороты, канцеляризмы,
  повторы; выравнивать терминологию; сокращать без потери смысла.
- **Запрещено:** менять числа, цитаты, имена, даты, названия, оговорки и выводы
  без отдельной проверки человеком.
- После любой правки — гейт **G2**: сверить правку с оригиналом (числа, цитаты,
  оговорки, выводы). Линтер стиля не отличает правду от выдумки.
- Запрещено удалять маркеры происхождения файлов и метаданные атрибуции,
  а также «маскировать» ИИ-текст под человеческий. Цель — качество, а не обход
  проверки ([docs/ai-use-policy.md](docs/ai-use-policy.md)).

## Конец сессии

1. `make gates` по изменённым файлам (G0, G1, G3, G5 — детерминированные).
2. Обнови `decisions` для всего, что решили; укажи `reopen_if`.
3. Запиши 3–7 выводов в память (Engram/agentmemory) — **только** со ссылкой на
   `journal_id`. Полный текст обсуждения остаётся в журнале и в память не идёт.
4. `make journal-verify` — цепочка журнала цела.

## Запрещено агенту

- писать разделы «Результаты» и «Обсуждение» без участия и проверки человека;
- добавлять ссылки без проверки их существования;
- удалять или перезаписывать записи журнала;
- отправлять неопубликованный текст во внешние облачные сервисы без явного
  разрешения человека;
- считать «зелёный» гейт доказательством того, что эксперимент был проведён
  (это доказывается данными, кодом и воспроизведением).
